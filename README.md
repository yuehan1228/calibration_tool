# 雷达自动标定工具

基于 Flask 的雷达-GNSS 自动标定 Web 工具。通过上传 GNSS 和雷达坐标文件，输入装船机姿态参数，自动求解刚体变换矩阵并计算标定误差。

## 功能

### 标定工具（主页）
- **坐标解析**：支持 CSV 和 TXT 格式的坐标文件
- **GNSS 格式支持**：
  - 局部坐标 (x, y, z)
  - 经纬度坐标 (B, L, H) — 自动转换为局部坐标
- **多坐标系变换**：支持旋转中心坐标系、臂架坐标系、溜筒坐标系
- **刚体变换求解**：基于 SVD 方法估计最优旋转平移矩阵
- **误差分析**：逐点欧氏距离误差，平均值和最大值
- **Web 界面**：浏览器直接操作，无需命令行

### 泊位坐标系建立
- 通过四个参考点（P0、Px、Py、Pz）的经纬度坐标计算 WGS84 → 泊位坐标系的 4×4 齐次变换矩阵
- 自动输出 numpy 格式矩阵，可直接复制到标定工具使用

### 大机姿态标定
- **回转数据分析**：通过不同回转角度下的 GNSS 数据拟合 2D 圆，得到回转中心 (X, Y) 和回转半径
- **俯仰数据分析**：通过不同俯仰角度下的 GNSS 数据拟合 3D 空间圆（PCA 降维），得到俯仰中心 Z
- **多天线支持**：支持 Ant1~Ant4 共 4 个天线的数据处理
- **数据格式灵活**：支持局部坐标和经纬度两种数据格式

## 快速开始

### 环境要求

- Python 3.8+

### 安装

```bash
git clone https://github.com/your-username/calibration_tool.git
cd calibration_tool
pip install -r requirements.txt
```

### 运行

```bash
python app.py
```

浏览器访问 `http://localhost:5000`

## 使用指南

本工具包含三个功能页面，通过顶部导航栏切换：

### 1. 标定工具（主页）

1. **选择 GNSS 数据格式**：
   - **局部坐标**：直接上传局部坐标系下的坐标文件
   - **经纬度**：上传 BLH 格式文件，并输入 WGS84 到泊位坐标系的转换矩阵

2. **上传坐标文件**：
   - GNSS 坐标文件（CSV/TXT）
   - 雷达坐标文件（CSV/TXT）

3. **选择目标坐标系**：
   - **旋转中心坐标系**：以大机旋转中心为原点（默认）
   - **臂架坐标系**：以臂架末端为原点（需输入臂架长度和伸缩距离）
   - **溜筒坐标系**：以溜筒连接点为原点（需输入臂架参数和连接点距离）

4. **输入大机姿态参数**：
   - 回转角、俯仰角
   - 旋转中心坐标 (X, Y, Z)
   - 臂架长度、伸缩距离（臂架/溜筒坐标系）
   - 连接点距离（溜筒坐标系）

5. **点击"计算"**，查看标定矩阵和误差

### 2. 泊位坐标系建立

1. 输入四个参考点的经纬度坐标：
   - **P0**：坐标系原点
   - **Px**：轴参考点（用于确定 Y 和 Z 轴方向）
   - **Py**：Y 轴方向点（沿臂架方向）
   - **Pz**：Z 轴方向点（竖直向上）
2. 设置高程差（默认 11.9 m）
3. 点击"计算"，获得 WGS84 → 泊位坐标系的 4×4 齐次变换矩阵
4. 将结果复制到标定工具中使用

### 3. 大机姿态标定

1. 选择 GNSS 数据格式（局部坐标或经纬度）
2. 上传回转数据文件（不同回转角度下的 GNSS 数据）
3. 上传俯仰数据文件（不同俯仰角度下的 GNSS 数据）
4. 输入 WGS84 转换矩阵（经纬度格式时）
5. 选择用于计算的天线：
   - **XY 天线**：选择顶部天线用于计算回转中心 X、Y
   - **Z 天线**：选择一个或多个天线计算俯仰中心 Z（多个天线取均值）
6. 点击"计算"，获得回转中心坐标、顶部天线高度和回转半径

## 数据格式

### 局部坐标格式（标定工具）

列名必须为 `x`, `y`, `z`：

```csv
x,y,z
1234.567,5678.901,12.345
1235.123,5679.456,12.678
```

### 经纬度格式 (BLH)

支持多种列名识别：

| 数据 | 支持的列名 |
|------|-----------|
| 纬度 | B, b, lat, latitude, 纬度, Lat, Latitude |
| 经度 | L, l, lon, longitude, 经度, Lon, Longitude |
| 高度 | H, h, height, alt, altitude, 高度, Height |

示例：

```csv
B,L,H
30.123456,120.654321,15.5
30.123556,120.654421,15.6
```

### 天线坐标格式（大机姿态标定）

支持四组天线（Ant1~Ant4）的坐标数据：

**局部坐标格式**：

```csv
Ant1_x,Ant1_y,Ant1_z,Ant2_x,Ant2_y,Ant2_z,Ant3_x,Ant3_y,Ant3_z,Ant4_x,Ant4_y,Ant4_z
1234.567,5678.901,12.345,1235.001,5679.002,12.500,...
```

**经纬度格式**：

```csv
Ant1_lat,Ant1_lon,Ant1_alt,Ant2_lat,Ant2_lon,Ant2_alt,Ant3_lat,Ant3_lon,Ant3_alt,Ant4_lat,Ant4_lon,Ant4_alt
30.123456,120.654321,15.5,30.123556,120.654421,15.6,...
```

### WGS84 转换矩阵格式

当选择经纬度格式时，需输入 4×4 齐次变换矩阵，仅支持 Python 列表格式：

```
[[ 6.73269087e-01, -3.69559710e-02,  7.38473418e-01,  1.40248457e+04],
 [ 5.90597897e-01,  6.27782467e-01, -5.07033820e-01, -9.53467436e+03],
 [-4.44862738e-01,  7.77511044e-01,  4.44492648e-01, -6.37393720e+06],
 [ 0.00000000e+00,  0.00000000e+00,  0.00000000e+00,  1.00000000e+00]]
```

## 坐标系说明

### 旋转中心坐标系

以大机旋转中心为原点的坐标系，适用于安装在旋转中心附近的传感器。

### 臂架坐标系

以臂架末端为原点的坐标系，适用于安装在臂架上的传感器。

**参数**：
- 臂架长度：旋转中心到臂架末端的距离
- 伸缩距离：臂架的伸缩量

### 溜筒坐标系

以溜筒连接点为原点的坐标系，适用于毫米波雷达等安装在溜筒上的传感器。

**参数**：
- 臂架长度、伸缩距离
- 连接点距离：臂架末端到溜筒连接点的距离

## 技术细节

### BLH → 局部坐标转换流程

1. BLH（经纬度）→ WGS84 直角坐标 (x, y, z)
2. WGS84 直角坐标 → 泊位局部坐标（通过 4×4 变换矩阵）

### 刚体变换求解

使用 SVD（奇异值分解）方法求解最优旋转矩阵 R 和平移向量 t，使得：

```
min ||R * P_radar + t - P_gnss||
```

### 大机姿态标定

**回转中心 XY**：通过 2D 最小二乘圆拟合计算，输入为回转过程中顶部天线在水平面的轨迹点。

**俯仰中心 Z**：通过 PCA 降维 + 3D 空间圆拟合计算，俯仰过程中天线轨迹在三维空间中形成一个圆弧，其圆心 Z 坐标即为俯仰中心。

### 泊位坐标系建立

通过四个参考点的 BLH 坐标建立 WGS84 ECEF → 泊位局部坐标的变换矩阵：
1. P0 定义平移分量（原点）
2. Px、Py、Pz 通过叉积计算构建正交基，定义旋转分量
3. Y × Z → X，再 X × Y 正交化 Z
